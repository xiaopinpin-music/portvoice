# PortVoice

PortVoice is an accessibility-focused macOS application for blind and VoiceOver users.

## Problem

Blind users often cannot determine whether a USB device, storage device, audio interface, or display has successfully connected or disconnected.

## Goal

Provide immediate spoken feedback when devices are connected or removed.

## Planned Features

- USB connected announcement
- USB disconnected announcement
- Display connected announcement
- Display disconnected announcement
- VoiceOver-friendly interface
- Start at login

## Future Features

- Device name recognition
- Device categories
- Custom aliases
- Multiple languages
- Custom sounds

## Status

Early prototype planning.
