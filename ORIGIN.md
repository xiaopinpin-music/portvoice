# PortVoice Origin

PortVoice started from a simple daily frustration.

Sometimes a Mac user connects a USB device, external drive, HDMI display, card reader, phone, or audio interface and wants immediate confirmation that the device was actually detected.

For sighted users, this may be visually obvious.

For blind users, it often requires guessing, opening Finder, checking system information, listening for another app, or asking someone else.

PortVoice was born from that gap.

## The Original Question

Why can a Mac visually show that something connected, but not simply speak it?

A user should not always need to look at Finder or depend on visual confirmation to know that a device has connected.

## Not Only for Blind Users

PortVoice is built from blind Mac user experience, but the idea is useful beyond blindness.

A spoken device confirmation can help:

- Blind and low-vision users
- Musicians connecting audio interfaces
- Creators using card readers and external drives
- Power users managing many devices
- Family users who want simple confirmation
- Anyone who wants feedback without looking at the screen

## Core Idea

The core idea is simple:

A device connects.

The Mac detects it.

PortVoice speaks what happened.

## Why It Matters

Small moments of uncertainty can create unnecessary friction.

Did the drive connect?

Did the display connect?

Did the card reader mount?

Did the phone appear?

Did the audio interface register?

PortVoice aims to remove that uncertainty with immediate spoken feedback.

## Product Spirit

PortVoice may look like a small utility, but it is built from a larger belief:

Modern technology should not require visual confirmation for basic confidence.

Accessibility should not be a separate, weaker experience.

A useful Mac utility can be designed from disability experience and still serve everyone.

## Mission

Build a practical macOS utility that makes device connection feedback clearer, more immediate, and more universal.
