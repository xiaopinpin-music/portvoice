# PortVoice Status

PortVoice has a working internal prototype.

Confirmed working on Ko Pinpin's Mac mini:

- App launches from Swift Package.
- Test speech works.
- USB connection announcement works.
- USB disconnection announcement works.
- Storage volume detection works.
- Storage volume name announcement works.

- Cadangan connected
