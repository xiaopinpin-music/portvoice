# PortVoice Branding

## Product Name

PortVoice

## Product Type

PortVoice is a macOS accessibility utility built from blind Mac user experience and designed as a universal tool for everyone.

## Creator

Created by Ko Pinpin / Xiao Pinpin.

## Intended Ownership Direction

The intended ownership direction is:

- PT Pinpin Music Indonesia

This aligns PortVoice with the broader Xiao Pinpin Music ecosystem.

Related website:

- xiaopinpinmusic.com

## Mascot

Mascot name:

- Bekcil

Mascot role:

- Friendly mascot
- Cheerful little duck helper
- Helpful guide for PortVoice users

Bekcil should feel:

- Friendly
- Cheerful
- Helpful
- Simple
- Professional enough for a real macOS utility

## Brand Positioning

PortVoice should remain a serious utility with a warm and accessible personality.

The product name stays professional:

- PortVoice

The mascot adds friendliness:

- Bekcil, the cheerful little duck helper

## Suggested Public Wording

PortVoice is an original macOS accessibility utility created by Ko Pinpin / Xiao Pinpin and developed from real blind Mac user experience.

Bekcil is the friendly mascot of PortVoice.

## Design Direction

Future icon or mascot design should avoid being too visually noisy.

Preferred direction:

- Simple duck mascot
- Clear silhouette
- Friendly expression
- Optional sound wave detail
- Optional subtle port/device connection symbol
- Works at small app icon size

## Accessibility Note

Branding must not depend only on visuals.

All mascot, icon, and brand elements should also be described clearly in text for blind and VoiceOver users.
