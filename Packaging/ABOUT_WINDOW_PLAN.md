# PortVoice About Window Plan

## Goal

Add an accessible About PortVoice window.

## Purpose

The About window should explain what PortVoice is, who created it, and the role of Bekcil.

## Initial Content

- PortVoice
- Current version
- Created by Xiao Pinpin
- Bekcil, the cheerful little duck helper
- Built from blind Mac user experience
- Designed as a universal accessibility utility for everyone

## Accessibility Requirement

The About window must be readable with VoiceOver.

Avoid image-only branding.

All important branding text must be available as real text.

## Future Additions

- Website link
- GitHub link
- License information
- PT Pinpin Music Indonesia ownership text, after legal direction is finalized
- Credits and acknowledgements

## Menu Bar Integration

the menu bar should include:

- About PortVoice

This should open the About window.

## Success Condition

A user can open About PortVoice from the menu bar and understand:

- What PortVoice is
- Who created it
- What Bekcil means
- Why the app exists
