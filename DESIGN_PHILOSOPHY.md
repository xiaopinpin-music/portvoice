# PortVoice Design Philosophy

PortVoice is designed from the lived experience of blind Mac and VoiceOver users, but it is not only for blind users.

The goal is universal access.

A good product should not create a lower-quality experience for disabled users.

A good product should let blind and non-blind users experience the same technology with the same confidence, dignity, and independence.

## Inspired Principle

PortVoice follows a simple product principle:

Design should not divide users into "normal users" and "accessibility users."

The same product should serve everyone.

Accessibility should not feel like a separate, reduced, or secondary mode.

## What This Means

PortVoice starts from a real accessibility need:

Blind users may not know when a USB device, storage drive, phone, card reader, audio interface, or display is connected or disconnected.

But the solution can help many people.

Examples:

- A blind user can hear that a drive connected.
- A sighted user can get confirmation without looking at the screen.
- A musician can hear that an audio interface connected.
- A creator can hear that a card reader connected.
- A power user can hear that an external drive disconnected.
- A family member can use the same app without needing a special accessibility version.

## Equal Feature Access

PortVoice should not become a limited tool only for blind users.

The target is not a small reduced product.

The target is a polished macOS utility that blind and non-blind users can both use fully.

The same features should be available to everyone.

## Product Standard

PortVoice should aim for:

- Clear spoken feedback
- VoiceOver-friendly controls
- Simple installation
- Simple uninstall
- Reliable device detection
- No unnecessary visual-only instructions
- No confusing setup
- No hidden technical steps for normal users

## Long-Term Vision

A user connects a device.

PortVoice speaks what happened.

No guessing.

No waiting.

No needing another person to confirm.

No separate lesser experience.

Just equal access to the same Mac experience.

## Mission

PortVoice is a small app with a larger purpose:

Build practical, universal, accessible technology from real disability experience, without limiting the product only to disability use cases.
