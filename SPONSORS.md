# Support PortVoice

PortVoice is an accessibility-focused macOS project created from the lived experience of a blind Mac and VoiceOver user.

This project is not only about announcing USB devices.

It is about equal access.

Blind users should be able to enjoy modern technology with the same confidence as sighted users, whether they are using a Mac, an iPhone, external storage, an audio interface, a card reader, or a display.

## Why PortVoice Exists

Many macOS device events are visually obvious to sighted users.

A sighted user can usually see when a drive appears, when a device connects, or when something changes on screen.

Blind users often need to guess, check Finder manually, ask someone else, or wait until another app gives a clue.

PortVoice aims to reduce that gap by speaking useful device connection and disconnection events.

## Accessibility Mission

PortVoice is built around a simple principle:

Blind and non-blind users should be able to experience the same technology with fewer barriers.

The goal is not to create a reduced or separate experience for blind users.

The goal is to make the primary macOS experience more understandable, immediate, and independent through spoken feedback.

## Where PortVoice Is Today

PortVoice has reached v0.9.0 — a universal build (Apple Silicon + Intel) for macOS 11 Big Sur and newer, in 42 languages.

Confirmed working:

- VoiceOver-first app interface
- Menu bar mode and start in background at login
- Device connect and disconnect announcements
- Storage volume announcements, spoken by name
- External display announcements
- Spoken voice that follows the Mac's language, offline

Confirmed example:

- Device connected
- Cadangan connected
- Display connected

## Why Support Matters

PortVoice is developed by Xiao Pinpin, a blind musician and Mac user building practical accessibility tools from real daily needs.

Support helps continue development toward:

- A public release
- A friendlier installer and uninstaller experience
- Better device recognition
- iPhone and iPad announced by name
- Audio interfaces and card readers announced by name

## Long-Term Vision

A blind user should be able to connect a device and immediately know what happened.

Examples:

- iPhone connected
- Samsung SSD connected
- Audio interface connected
- Display connected
- Cadangan disconnected

PortVoice is a small app with a larger purpose: practical independence, equal access, and better everyday Mac usability for blind users.
