# Building PortVoice

## Requirements

- macOS 14 or newer
- Xcode 16 or newer
- VoiceOver recommended for accessibility testing

## Goals for V0.1

- Launch application
- Verify accessibility labels
- Verify speech output
- Prepare for USB monitoring implementation

## Current Status

This branch contains the initial SwiftUI skeleton.

Implemented:

- App entry point
- Main window
- Enable/Disable toggle
- Status message area
- Test Speech button
- Speech service abstraction

Not yet implemented:

- USB connection detection
- Display connection detection
- Device name recognition
