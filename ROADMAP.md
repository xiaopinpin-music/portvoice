# PortVoice Roadmap

## V0.1 Prototype

Goal:
Prove that macOS can reliably announce device connection events.

Features:

- USB connected announcement
- USB disconnected announcement
- Spoken feedback
- Simple accessible interface
- Enable / Disable switch

---

## V0.2

Features:

- Display connected announcement
- Display disconnected announcement
- Notification sound option
- Improved VoiceOver accessibility

---

## V0.3

Features:

- Start at login
- Menu bar mode
- Background operation

---

## V1.0 Public Release

Features:

- DMG installer
- 15-day trial
- License key activation
- English announcements
- Indonesian announcements

---

## Future Features

- Device name recognition
- Device category recognition
- Custom aliases
- Custom sounds
- Multiple voices

Examples:

- Samsung SSD 990 Pro connected
- Apollo Twin X connected
- My Book Thunderbolt Duo connected

---

Mission:

Create an affordable accessibility tool for blind macOS users.
